Pandas Cheat Sheet

| Code                | Meaning              |
| ------------------- | -------------------- |
| `df.head()`         | First 5 rows         |
| `df.head(10)`       | First 10 rows        |
| `df.tail()`         | Last 5 rows          |
| `df.shape`          | Rows + columns       |
| `df.columns`        | Column names         |
| `df.isnull()`       | Find missing values  |
| `df.isnull().sum()` | Count missing values |
